| Onde | Link |
|------|------|
| **GitHub Pages** | https://gustavo-vieira-unasp.github.io/goofy-jello-support-material/ |
| Local | abra [`index.html`](index.html) na raiz (use um servidor estático para carregar `assets/` corretamente) |

### Publicar no GitHub Pages

1. Faça push de `index.html`, `assets/`, `.nojekyll` e este README para a branch `main`.
2. No GitHub: **Settings → Pages → Build and deployment → Branch `main` → folder `/ (root)`**.
3. Aguarde o build e use a URL em *Settings → Pages*.

## Estrutura
